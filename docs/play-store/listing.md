## English (en-US) — default

**App name**

```
Pocket Reviewer: AI PR reviews
```

**Short description**

```
Reviews GitHub pull requests with Claude when they are shared in your chat.
```

**Full description**

```
Pocket Reviewer is a code reviewer that lives on your phone. When a teammate shares a GitHub pull request in Google Chat or Slack, the app notices the link, reviews the change with Claude against your team's rules, and posts the review on GitHub.

It runs entirely on your device with your own accounts. There is no server, no account to create, no ads and no tracking. The app is free and open source.

HOW IT WORKS
• A pull request link arrives in a chat notification.
• The app reacts to the message so your team knows it is being looked at.
• Claude reviews the diff against your rules.
• If there are findings, the review is posted on GitHub and the app replies in the thread.
• If the change is clean, you can approve and merge it — or let the app do it once CI passes.

YOU STAY IN CONTROL
• Manual mode (the default): you confirm each step — review, post, approve, merge.
• Autonomous mode: the app does everything on its own, and never merges with failing CI or merge conflicts.
• Choose which GitHub owners and repositories are reviewed, and which chat spaces or channels to listen to.

YOUR RULES
• Start with the built-in rules: correctness, security, data, APIs, tests, performance and maintainability.
• Or point the app at markdown files in a GitHub repository, or paste your own.
• A CLAUDE.md or AGENTS.md in the repository being reviewed is always taken into account.

CONFIGURABLE
• Claude model, review language, merge method, delays and CI handling.
• Every message and reaction the app posts in chat.
• Works with GitHub.com and GitHub Enterprise Server.
• English and Spanish, light and dark theme.

WHAT YOU NEED
• A GitHub personal access token.
• An Anthropic API key (reviews use your own API account).
• Optional: a Google Workspace account or a Slack token, to react and reply in chat.

PERMISSIONS
The app needs notification access to detect pull request links in your chat notifications. Notification content is processed on your device only and is never sent to the developer. See the privacy policy for details.

Pocket Reviewer acts with your credentials. Reviews are generated by an AI model and can be wrong: keep branch protection and required checks enabled on repositories you let it merge.

Source code, documentation and issue tracker: https://github.com/carolinasolfernandez/pocket-reviewer
```
